╚════════════════════════════════════════════════════════════════════════════╝

1. Configure environment:
   $ cp .env.audio.example .env

2. Create storage directory:
   $ mkdir -p storage/app/audios

3. Run database migration:
   $ php artisan migrate

4. Start development server:
   $ php artisan serve

5. Test with cURL:
   $ curl http://localhost:8000/api/audios

╚════════════════════════════════════════════════════════════════════════════╝

File Upload (POST /api/audios):
  • title: required, string, max 255 chars
  • description: optional, string, max 1000 chars
  • file: required, audio file, max 50MB
  • Formats: MP3, WAV, M4A

File Update (PUT /api/audios/{id}):
  • title: optional, string, max 255 chars
  • description: optional, string, max 1000 chars

Database Schema:
  • Table: audios
  • Columns: id, title, description, file_path, duration, file_size, 
             mime_type, status, created_at, updated_at
  • Indexes: title (search), status (filtering)

╔════════════════════════════════════════════════════════════════════════════╗
║                       TESTING THE API                                      ║
╚════════════════════════════════════════════════════════════════════════════╝

List Audios:
  $ curl http://localhost:8000/api/audios

Upload Audio:
  $ curl -X POST http://localhost:8000/api/audios \
    -F "title=My Audio" \
    -F "file=@audio.mp3"

Get Audio Details:
  $ curl http://localhost:8000/api/audios/1

Update Audio:
  $ curl -X PUT http://localhost:8000/api/audios/1 \
    -H "Content-Type: application/json" \
    -d '{"title":"Updated"}'

Delete Audio:
  $ curl -X DELETE http://localhost:8000/api/audios/1

Search Audios:
  $ curl "http://localhost:8000/api/audios/search?q=keyword"

Get Statistics:
  $ curl http://localhost:8000/api/audios/statistics
