VALIDATION RULES
================

Upload (StoreAudioRequest):
- title: required, string, max 255
- description: nullable, string, max 1000
- file: required, mimes(mp3,wav,m4a), max 50MB

Update (UpdateAudioRequest):
- title: nullable, string, max 255
- description: nullable, string, max 1000

QUICK START
===========

1. Setup environment:
   cp .env.audio.example .env

2. Create storage directory:
   mkdir -p storage/app/audios

3. Run migrations:
   php artisan migrate

4. Start server:
   php artisan serve

5. Test API:
   curl -X POST http://localhost:8000/api/audios \
     -F "title=Test" -F "file=@audio.mp3"
